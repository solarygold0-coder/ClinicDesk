# Roadmap

## Phase 1 — Foundation
Tauri/React shell, RTL design system, SQLite schema, CI.

## Phase 2 — Core records
Patient CRUD, clinic/doctor CRUD, validation, duplicate detection, search.

## Phase 3 — Scheduling
Appointments, conflict prevention, Friday/Saturday blocking, status workflow and two-day alerts.

## Phase 4 — Records operations
Attachments, audit log, backup/restore, inactivity review.

## Phase 5 — Windows release
Accessibility/RTL regression, performance tests, signed installer pipeline and release artifact.
