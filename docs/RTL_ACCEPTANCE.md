# UI acceptance criteria

- Every application surface inherits RTL from the document root.
- Sidebar is physically on the right in Arabic.
- Form labels, table headers, pagination and dialogs align with RTL flow.
- File numbers, phone numbers and identifiers may use isolated LTR spans without changing page direction.
- Empty states always provide the next useful action.
- A user can reach patient creation, appointment creation and search from the dashboard in one action.
- Clinics and doctors show an explicit empty state on first run rather than seed data.
