# ClinicDesk 5

إعادة بناء كاملة لتطبيق سجلات المرضى.

## التقنية
Tauri 2 + Rust + React 19 + TypeScript + SQLite.

## مبادئ الإصدار
- RTL عربي من جذر المستند.
- لا توجد شاشة تسجيل دخول أو صلاحية Admin عند التشغيل.
- لا عيادات ولا أطباء افتراضيون؛ يبدأ النظام فارغًا.
- قاعدة SQLite محلية مع WAL وForeign Keys.
- أرقام ملفات المرضى متسلسلة ولا يعاد استخدام المحذوف منها.
- فصل الواجهة عن طبقة أوامر Rust وقاعدة البيانات.

## الفرع
`tauri-react-rebuild`

هذه المرحلة هي الأساس المعماري وواجهة لوحة التحكم. المرحلة التالية تضيف repositories/services وعمليات CRUD الفعلية واختبارات التكامل.
